# Blockchain-Based E-Voting Portal

An educational project demonstrating basic blockchain concepts through an electronic voting portal.

## About the Project

This is a beginner-level project created to explore how blockchain concepts can be applied to electronic voting systems.

I am currently learning programming, web development, blockchain fundamentals, and how to use AI tools effectively to turn ideas into practical projects.

## Features

- Voter Login System
- One Vote Per Voter (Demo)
- Candidate Selection
- Live Voting Results
- SHA-256 Hashing
- Blockchain-Style Ledger
- Previous Hash Linking
- Chain Verification
- Tampering Demonstration

## Technologies Used

- HTML
- CSS
- JavaScript
- SHA-256

## What I Learned

- Basic blockchain structure
- Hash generation
- How blocks connect using previous hashes
- Data integrity concepts
- Basic web development
- Using AI tools as a learning assistant

## Project Purpose

This project is developed for educational and demonstration purposes only. It is not a production-ready voting system or a distributed blockchain network.
